## Problem (original report, condensed)

> I just recently updated Caelestia KDE to the recent version v2.4.3 and I have encountered an issue where the lock screen falls back to the built-in lock screen despite the command `kreadconfig6 --file plasmashellrc --group "Shell" --key "ShellPackage"`  outputs correctly as "caelestia.desktop" and the `/usr/lib/kscreenlocker_greet --testing` actually shows the caelestia lock screen.
>
> I checked errors related to kscreenlocker in journalctl and found that the module 'Caelestia.Services" is not found.
>
> Aside from that, I couldn't see the caelestia SDDM theme, not sure if I did something wrong even though the installer's full log says its OK

Troubleshooting the reporter had already done (condensed): re-setting `ShellPackage` via `kwriteconfig6` (reads back correctly), reinstalling v2.4.3 (was working on v2.4.2), `kscreenlocker_greet --testing` works, reboot/relogin does not help. Caelestia version v2.4.3, distro CachyOS.
